# Kecap Mringin

Project ini merupakan aplikasi mobile sederhana berbasis React Native dan Expo yang menampilkan katalog produk kecap dari brand **Kecap Mringin**.

## Tentang Project
Aplikasi ini dibuat untuk menampilkan daftar produk kecap dengan informasi seperti:
- Nama produk
- Harga
- Varian produk
- Status ketersediaan stok

Tujuan utama dari aplikasi ini adalah untuk memberikan tampilan katalog produk yang rapi dan mudah dibaca, dengan interaksi sederhana saat pengguna memilih produk.

## Fitur yang Dikerjakan
- Membuat struktur project React Native dengan Expo
- Menampilkan daftar produk menggunakan array of objects
- Menggunakan TypeScript untuk tipe data produk
- Menggunakan `FlatList` untuk menampilkan data secara berulang
- Membuat fungsi custom untuk menangani klik produk
- Menampilkan alert saat produk dipilih
- Menggunakan style eksternal dari file `src/constants/styles.ts`
- Menambahkan tampilan status stok dan varian produk

## Struktur Utama
- `src/app/index.tsx` : halaman utama aplikasi
- `src/constants/styles.ts` : file style untuk desain UI

## Teknologi yang Digunakan
- React Native
- Expo
- TypeScript

## Kesimpulan
Project ini adalah contoh aplikasi katalog produk sederhana yang fokus pada tampilan UI dan interaksi dasar pengguna dalam aplikasi mobile.
